## Speaking implementation

`/speaking`, reachable from Chơi & học and word detail. First five approved words form Nói cùng Cáo, or a selected sense; optional exact saved sentence, whole-target IPA/audio. User-gesture mic with supported MIME,10-second cap, real timer/stop, replay, rerecord, permission/error recovery. Finite mono16kHz WAV replay with real duration. Temporary Blob URL only, cleanup/revoke, stop tracks/late permission/hidden/scope changes, cancel generations and target revisions. No recording in IndexedDB/cloud/backup. Sample/record/playback independent of model.

Dedicated origin/version CacheStorage, explicit≈377MB download, quota bound/progress/SHA256+size/complete marker, cancel/retry and model-only clear/delete. Hashing uses pinned MIT `@noble/hashes2.4.0` incremental SHA256 in Worker; stores bounded16MiB ONNX parts in CacheStorage instead of retaining several355MB JS copies or one giant Cache.put, which Chromium rejected. Generated runtime from pinned Transformers.js3.8.1 served lazily; not SW install precache. Model-only cache survives public-shell SW upgrades and can be removed without library/auth/settings. Worker loads verified cached files, disables remote inference/model fallback, runs WASM/CTC from PCM16kHz. Actual browser inference uses public licensed audio via a virtual MediaStream, never real mic.

CMUdict US per-token variants from bounded same-origin/no-store route; unknown/heteronyms abort rather than guess. Unprompted CTC global edit-distance alignment, broad phone compatibility, alternate variants, silence/clipping/low-evidence abstention. **No numeric pronunciation score/calibration claim**. Green/orange/red/grey describe tentative machine observations, explicitly not certainty that a child was wrong. Red means no aligned acoustic evidence; missing-word recall/false-error behavior is not validated for children. No SRS/reviewEvent mutation; progress rewards attempted words only.

Optional gesture Gemini advice receives only exact target and selected bounded expected/heard phone evidence/index/status, no child audio/name/email/full library. Existing key off/restore/private override rules apply; user confirms Free Tier/no billing. Single request, timeout/cancel, plain-text/index/schema validation, no tools, paid fallback, automatic retry or key rotation. Quota/off/invalid/refusal errors retain existing VI advice. Live provider/child eligibility remains unverified; fixture-only API test.
