# One-save edit, partial groups and persistent navigation — ADR076

Founder12/10 asks to fix image/edit saves, partial group additions, grammar completion, deletion location, dated-set deletion, global navigation and illustrated empty states. This is local code and isolated fixture verification. No founder browser/account/data, actual AI calls, SQL/production integration, deploy, Git commit/push or Vercel environment edits in this change.

The editor now has one explicit Save and no additional review checkbox/proposal/extra-content save. Pictures imported through the editor are staged until that Save; other picture-preparation routes still save their chosen image directly. The transaction covers word/example approval, owned media and linked learning-content revisions. A WebCrypto hash inside an active IndexedDB transaction originally caused premature commit; `Dexie.waitFor` keeps the enclosing transaction active. A failed content write rolls back the word and image. Different tabs remain protected by root revision and supplemental row-version checks. Existing grammar variants/evidence/IPA are preserved; changed sentence text clears its old IPA/hint. Empty optional sections do not block image-only edits. An explicitly cleared supplemental form removes only its own row.

Grouped legacy grammar previously changed the representative title while `grammarKey` still used that title. Its displayed reference could not match a raw stored row. The grouping projection now retains the original representative title/key. One grouped grammar alone can be saved; one word can then be added to that group. Selection does not require every word or grammar item. Exact dedup/no-op reporting remains.

Word detail/edit trash is in the top toolbar. Each dated lesson tile has a trash action with confirmation. Removing a lesson tombstones the container and membership links, retaining words, examples and grammar in the global library; the deleted set is unavailable as a practice source. Grammar animation returns to step1 after its last stage, pauses when hidden and keeps reduced-motion/manual controls.

`SubmitButton` gives pending/success/error states and red errors immediately above the action. Applied to word/group/deck/set/note/key/profile saves, dictionary/image actions, worksheet analysis/save, account sign-in/out/refresh/library, cloud sync/source upload/delete/transfer and confirmed deletion. Input changes clear stale feedback where appropriate. Exercise/game answer feedback keeps its existing correct/incorrect states; passive background sync and file pickers are not submit actions. Field-specific edit validation stays beside the input; errors focus/open the relevant section. Profile persistence returns a result instead of claiming success after a caught storage failure. No toasts/raw provider bodies/secrets are displayed.

Navigation is shared by all learning routes, public Welcome/404 and page-error recovery, with bottom safe-area padding on mobile and side navigation on desktop. Removed game-only nav suppression; sticky save controls clear the footer. Empty states use the existing original Fox illustration, strong heading and useful CTA. Picture preparation distinguishes no words from no missing pictures and clamps a page after an image is saved.
