# ADR054 — Hồ sơ/avatar, clipboard mobile, xóa và ngữ pháp từ câu

11/10/2026, local only. Founder requests all five changes from four attached screenshots. No real founder browser/account, Google AI inference, GitHub/Vercel/environment/remote operation or publishing performed.

## Delivered behavior

- Header `/profile` link uses Google avatar with safe fallback or local Fox/Cat/Dog choice. Display name/avatar are whitelisted small local preferences; choices survive reload and do not mutate Google metadata/cloud profile. Profile contains existing sign-in/logout/account/transfer/current-library controls moved from Settings; `/account` remains usable. Sign-in appears before personalization. Four main destinations: Today, My words, Play & learn, Settings; bottom on mobile, left on desktop. Avatar buttons are an even 2×2 on mobile. No avatar upload/new account system/multiple child profiles implied.
- Removed the Google data/eligibility disclosure from Settings. Upload consent, image review, actionable cost notice, private-image check and actual auth boundaries remain at relevant actions. Removal is presentation steering, not a claim of provider eligibility/free quota/retention.
- New mobile Paste copied image button calls `clipboard.read` only on a user gesture; existing native paste also checks file clipboard items. One actual image follows the same 10MB/20MP format/signature validation, normalization/metadata stripping/draft/preview as upload. Text/URL-only clipboard, unavailable API, denied permission or multiple images get clear recovery via file chooser. Normal text paste remains normal. Never fetches a clipboard URL or automatically sends AI.
- Inline confirmed delete controls cover words by sense, groups, custom decks, dated sets, sentences, patterns and grammar. Confirmation snapshots scope/version; newer concurrent edits produce an error and are kept. Versioned tombstones preserve history and backup/sync. Last active sense deletion frees the entry active key. Deck/group deletion does not delete library words/sentences; set deletion removes its links and its own supplemental sentences/grammar, retaining shared words/other sets. Pattern/grammar deletion clears just that section; supplementary sentence deletion also removes its attached sections, explicitly described before confirmation. Search rebuild ignores deleted examples/links/lessons. No new SQL/migration.
- Gemini worksheet prompt/schema now cover useful content words from sentence-only worksheets plus bounded `learning[]`: literal source sentences, inferred sentence patterns and complete grammar. Transcript evidence/target/completeness/whole-sentence IPA validate before draft replacement. Field `pattern` survives provider-schema pruning (only regex keywords stripped). Review can edit suggestions; English edits clear IPA/hints, empty IPA stays null. Save is atomic and tied to the lesson/approved sense revision, optional drafts/archive retained. Prepared fallback preserves “Who are they?” and “They are a family.” as source and explains who/they/are/a family as supplementary teaching. Does not infer grammar from unreadable/unmatched text.
