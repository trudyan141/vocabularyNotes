# Free picture source notices

Words for Kids downloads only pinned source SVG paths and converts them to resized JPEGs. Imported records retain creator, source permalink, license link and the change notice; users explicitly select pictures.

- Google Noto Emoji 2D SVGs: copyright 2013 Google, Inc.; Apache-2.0. Source directory notice in noto-LICENSE.txt; full terms in Apache-2.0.txt. Font OFL is a separate license and is not used for these images.
- Twemoji graphics: Twemoji contributors, CC BY 4.0. Full terms in twemoji-LICENSE-GRAPHICS.txt.
- Microsoft Fluent Emoji flat SVGs: copyright Microsoft Corporation, MIT. Full terms in fluent-LICENSE.txt.

Source revisions and file paths: src/lib/media/free-picture-sources.json. No Microsoft/Google/Twemoji artwork is claimed as original Words for Kids artwork.
